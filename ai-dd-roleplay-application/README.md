# 🎲 Летописец — ИИ-мастер D&D 5e

Локальный веб-сервис с браузерным интерфейсом. Запуск: двойной клик по `launcher/start.bat` (Windows) или `launcher/start.sh` —
лаунчер сам подготовит базу, найдёт свободный порт, запустит сервер и откроет браузер.

## Как собрать один exe
1. Стек: Next.js (Node) + PostgreSQL (Drizzle). Для «portable»-варианта положите рядом портативный Node и PostgreSQL
   (или замените хранилище на embedded-Postgres) и пропишите `DATABASE_URL` в `.env`.
2. Оберните `launcher/launcher.mjs` в exe: `npx @yao-pkg/pkg launcher/launcher.mjs --targets node20-win-x64 -o Letopisets.exe`
   (или Inno Setup / Electron-оболочка с тем же лаунчером). Exe запускает сервер и открывает адрес в браузере сам.

## Папки данных
- `data/images` — ваши картинки для персонажей и локаций (выбор в интерфейсе «из папки»).
- `data/generated` — картинки, созданные ИИ.

## Что внутри
- Подключения: LM Studio/Ollama/любой OpenAI-совместимый сервер, OpenRouter, OpenAI, DeepSeek, Anthropic, Gemini — по ключу или локально.
- Разные модели для задач: мастер, режиссёр (размышление), писарь, память, промты картинок, переводчик.
- Контекст-движок: бюджет по группам, триггеры / «всегда» / «по логике» / выкл, липкость карточек, стабильный префикс (кеш), отчёт «что в контексте».
- Блокнот памяти: многоуровневое сжатие (сцены → главы → хроника), политика «что можно/нельзя удалять», «никогда не забывать».
- Кубики: сервер бросает криптографическим ГСЧ; один бросок на ход, мастер не пишет отдельный ответ после броска.
- Откат: правка/удаление/регенерация откатывают изменения карточек и пересжимают ложные факты из блокнота.
